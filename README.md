# 国风城市电影海报生成技能 · 分享版

> 输入一个**地名**（城市 / 区县 / 乡镇），自动联网调研该地真实文化符号，生成一套「国风城市电影海报」文生图提示词，并出一幅 9:16 国风收藏级海报（底图由 AI 出图，左侧 30% 中文文字栏由脚本矢量精确叠加，杜绝出图中文乱码）。

成品效果见 `示例_苏州/` 文件夹（苏州成图 + 文字配置 + 完整提示词）。

---

## 一、三步安装

1. 把本包里的 **`guofeng-poster`** 文件夹，整体复制到你电脑的
   `C:\Users\你的用户名\.workbuddy\skills\guofeng-poster\`
   （即 WorkBuddy 的技能目录；若 `skills` 文件夹不存在就新建一个）。
2. 确认本机有 **Python 3**（WorkBuddy 自带托管 Python；或用系统 `python3` 也行）。
3. 确保装了 **Pillow**：没装的话，在命令行跑 `pip install pillow` 即可。
   （脚本首次运行会自动检测并安装，一般无需手动。）

> 中文字体用 Windows 自带的（微软雅黑 / 宋体 / 楷体 / 华文行楷 / 黑体），正常机器都有，免安装。

---

## 二、三步使用

1. 打开 WorkBuddy，直接说一句话，例如：
   **「帮我做一张成都的国风海报」** 或 **「杭州」**。
2. 技能会联网查该城的真实地标 / 市花 / 非遗 / 特色食物等，先给你一套**完整提示词**；
   出图前会提示：单次 AI 出图约消耗 **5–10 credits**。
3. 确认后自动出底图 + 叠加中文，最后把成图与提示词一起交给你。

---

## 三、常见问题

| 问题 | 处理 |
|---|---|
| 提示 `No module named PIL` | 命令行执行 `pip install pillow` 后重试 |
| 左侧文字乱码 / 方块 | 字体目录非 `C:/Windows/Fonts` 时，设置环境变量 `GF_POSTER_FONT_DIR` 指向你的中文字体目录 |
| 出图中文仍是乱码 | 这是 AI 出图通病，本技能已规避：左侧文字由脚本叠加，**不要**让 AI 直接画左侧中文 |
| 想改文字内容 | 编辑技能里的 `spec.json`（字段说明见 SKILL.md），再跑 `compose.py` |
| 想换模板/提示词 | 改 `references/template.md` 里所有 `【】` 占位符即可 |

## 四、文件结构

```
guofeng-poster/
├── SKILL.md            # 工作流与设计铁律（AI 读取）
├── compose.py          # 把精确中文矢量文字叠加到 AI 底图左侧 30% 文字栏
├── references/
│   └── template.md     # 国风海报提示词模板（所有【】占位符）
└── requirements.txt    # 依赖：pillow
示例_苏州/               # 苏州成图 + 文字 spec + 完整提示词（演示用）
```

## 五、设计要点（给想二次创作的朋友）

- **左侧中文绝不靠 AI 出图**：文生图模型对中文几乎必乱码，所以左侧文字栏由 `compose.py` 重绘为干净暖白宣纸面板，再用矢量字体（主标题用华文行楷）叠加。
- **真实优先**：模板里所有 `【】` 都要和该城真实对应，禁止混用不同城市地标或民族服饰。
- **硬性禁止项**（已写进提示词）：侧脸剪影、双重曝光、九宫格拼贴、建筑变形、地标混用、多指、霓虹色、塑料感 3D、水印、品牌 Logo、中文乱码。
